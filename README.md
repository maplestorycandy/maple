## ⚔️ 五大經典職業系統

* 🔴 **劍士 (Warrior)**：主屬性 STR，手持英雄雙手劍，近戰爆發與高血量。
* 🔵 **魔法師 (Magician)**：主屬性 INT，手持元素魔杖，超大範圍落雷與全屏天怒審判。
* 🟢 **弓箭手 (Bowman)**：主屬性 DEX，手持精靈長弓，超高暴擊率與暴風神射連弩。
* 🟣 **盜賊 (Thief)**：主屬性 LUK，日月標與拳套，雙飛金鏢與極速六連擊。
* 🟠 **海盜 (Pirate)**：主屬性 STR/DEX，重火槍與指虎，雙連烈焰彈與昇龍踢擊。

## 🛠️ GitHub Pages 自動部署說明

本專案已配置 GitHub Actions 工作流程（`.github/workflows/deploy.yml`），每次推送程式碼至 `main` 分支時，GitHub 會自動：
1. 透過 Godot 4.3 Compatibility 引擎將遊戲導出為 WebAssembly (HTML5)。
2. 自動注入 `coi-serviceworker.js` 解決瀏覽器跨域隔離 (COOP/COEP) 需求。
3. 自動發布至 `gh-pages` 分支並開啟網頁版！
